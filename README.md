# 顔マスク処理アプリ

## 概要

画像内の顔を検出し、顔の位置に絵文字のマスクを重ねて表示する Web アプリです。JPEG・PNG・WebP を一度に最大10枚まで選べます（各画像10 MB以下）。顔検知は外部 API に依頼し、API キーはサーバー側で使用します。

追加機能の要件と受入条件は [.docx/specification.md](.docx/specification.md)、過去の API 疎通記録は [docs/api-test-log.md](docs/api-test-log.md) を参照してください。要件の改訂は実装完了を意味しません。実装と検証の進捗は今後のコミットで記録します。

## インストール

Node.js と npm、および利用可能な顔検知 API の URL とキーを用意してください。

1. 依存関係をインストールします。

   ```powershell
   npm ci
   ```

2. 設定ファイルを作り、`FACE_API_URL` と `FACE_API_KEY` を実際の値に書き換えます。

   ```powershell
   Copy-Item .env.example .env.local
   ```

   `.env.local` は Git に登録しないでください。顔検知 API が未設定の場合、画面は開けますがマスク処理は失敗します。

## 使い方

1. 開発サーバーを起動し、ブラウザで `http://localhost:3000` を開きます。

   ```powershell
   npm run dev
   ```

2. 画像をドラッグ＆ドロップするか、枠をクリックして選びます。プレビューで画像を確認し、「画像をマスク」を押すと結果が一覧表示されます。複数枚のときはプレビューの矢印で画像を切り替えられます。

3. API を直接試す場合は、サーバー起動中に次の例を実行します。`face.jpg` はリポジトリに含まれる確認用画像です。

   ```powershell
   curl.exe -X POST -F "file=@face.jpg" http://localhost:3000/api/detect
   ```

   外部 API に接続できれば、検出された顔の座標を含む JSON が返ります。顔が見つからない場合や接続できない場合は、画面にエラーを表示します。

## 運用

1. このリポジトリをフォークし、作業用ブランチを作成します。
2. 変更後に `npm run lint` と `npm run build` を実行して確認します。API を使う機能は、有効な設定を用意して実際の画像でも確認してください。
3. 変更内容と確認結果を書いてプルリクエストを送信します。

本番運用では `npm run build` の後に `npm run start` で起動します。API キーは環境変数として安全に設定してください。

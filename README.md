# Face Mask Studio

写真の顔を検出して隠し、範囲やマスクを調整して保存するWebアプリです。Next.js、ReactとCanvasを使用しています。手動編集とサンプルは顔検知APIの設定なしで使えます。

要件と受入条件は [.docx/specification.md](.docx/specification.md)、構成や状態管理は [docs/design.md](docs/design.md)、実施した確認と未確認事項は [docs/validation.md](docs/validation.md) を参照してください。

## 起動

確認環境はWindows、Node.js 20.19.1、npm 10.8.2です。

```powershell
npm ci
npm run dev
```

ブラウザで `http://localhost:3000` を開きます。まず「サンプルで試す」を選ぶと、図形から作った画像で編集と保存を試せます。サンプルの範囲はデモ用で、自動検出の結果ではありません。

自動検出を使う場合は、設定ファイルを作成し、接続先とキーを設定してください。

```powershell
Copy-Item .env.example .env.local
```

`FACE_API_URL` はCompreFace互換の顔検出エンドポイント、`FACE_API_KEY` は利用可能なキーです。`.env` と `.env.local` はGit対象外です。実値を `.env.example` やクライアントのコードに書かないでください。

## 使い方

1. 「画像を選ぶ」、ドラッグ＆ドロップ、Ctrl/Cmd+V、貼り付けボタン、カメラから画像を追加します。JPEG、PNG、WebPを最大10枚保持できます。1枚10 MiB以下、各辺8192px以下、2400万画素以下です。不正な画像が混ざっていても、有効な画像は取り込みます。
2. 画像を選択するとプレビューが開きます。「未処理の画像を順に検出」を押すと、画像をサーバー経由で外部の顔検知サービスへ送ります。処理は一枚ずつ進み、中断できます。失敗した画像も手動で編集できます。
3. 単色、モザイク、ぼかし、スタンプを選びます。顔ごとのON/OFF、色、不透明度、強さ、範囲の大きさと位置を調整できます。手動で囲むか、中央に範囲を追加して数値を編集できます。元に戻す／やり直す操作は画像ごとに保持します。
4. 枠のプレビュー、比較、ズームとパンで隠れ方を確認します。信頼度の下限は再通信なしで変更できます。信頼度不明の顔と手動範囲は絞り込みの対象から外れません。
5. 名前とPNG/JPEGを選んで保存します。JPEGは画質を指定でき、透明な部分を白で合成します。コピーする画像はPNGです。出力には検出枠、比較表示、ズームを含めません。

画像を切り替えても編集を復元できます。削除や全消去でセッションから取り除きます。Undo/Redoは最大50件で、Ctrl/Cmd+Z、Ctrl/Cmd+Shift+Zも使えます。テーマはOS追従、ライト、ダークから選べ、表示言語は日本語と英語を切り替えられます。「このマスク設定を次回も使う」で既定のマスクを保存できます。

## カメラとClipboard

カメラと画像のClipboard APIは、HTTPSまたはlocalhostとブラウザの許可が必要です。カメラはボタンを押したときだけ要求し、撮影や取消、ページ終了時に停止します。非対応や拒否の場合は、ファイル選択やダウンロードを利用してください。スマートフォンからPCの開発サーバーへ通常のHTTPで接続すると、安全な接続の条件を満たさない場合があります。

画像の貼り付けはテキスト欄の通常の貼り付けを妨げません。Clipboardへの書き込みはコピー操作時だけ行います。

## データの扱い

画像を選ぶだけでは外部へ送信しません。自動検出を実行すると、写真を顔検知サービスへ送ります。サービス側の保存期間と利用条件は運用者に確認してください。

アプリは画像、座標と編集履歴を開いているページ内だけに保持します。サーバーのファイルやデータベース、ブラウザの永続ストレージには保存しません。ページを更新すると画像と履歴は消えます。ブラウザに保存するのは言語、テーマ、マスクの既定値、ガイドの既読状態だけです。

ブラウザは画像の向きを反映してピクセルから画像を再生成し、同じ画像をプレビューと検出に使います。出力へ元画像のEXIFや位置情報を引き継ぎません。顔検出には見落としや誤検出があり、薄いマスク、弱いぼかし、細かいモザイク、OFFや閾値の変更で顔が残る場合があります。保存前に確認してください。

## 検証

```powershell
npm test
npm run lint
npm run typecheck
npm run build
npx playwright install chromium
npm run test:e2e
```

単体テストは外部APIを差し替えて実行します。ブラウザ試験も生成画像とAPIモックを使い、実写真や実キーの送信を必要としません。PCとスマホ幅をChromiumで確認します。ブラウザ試験は本番ビルドを作り、`127.0.0.1:3100` に検証用サーバーを起動します。レポートはGit対象外の `output/playwright/` に保存します。

`test-detect.mjs` は以前からある、外部APIへ直接画像を送る手動疎通用スクリプトです。通常の自動テストでは実行しません。過去の疎通記録は [docs/api-test-log.md](docs/api-test-log.md) にあります。

## 運用とライセンス

本番では `npm run build` の後に `npm run start` で起動します。APIキーをサーバーの環境変数に設定してください。変更は作業用ブランチで行い、lint、型検査、テスト、本番ビルドを確認してからレビューします。

現時点でリポジトリ全体のライセンスは指定されていません。利用や再配布の条件は管理者に確認してください。スタンプとサンプルはアプリ内で図形を描き、外部素材や絵文字フォントを使用しません。
